CargoCalc — готовый учебный проект

Состав:
- ASP.NET Core Razor Pages (.NET 10)
- SQLite и Entity Framework Core
- Добавление заказчиков и перевозчиков
- Создание и удаление заявок
- Добавление и удаление предложений перевозчиков
- Сравнение по минимальной цене, минимальному сроку и оптимальному балансу
- Начальные демонстрационные данные создаются автоматически

КАК ЗАПУСТИТЬ В VISUAL STUDIO:
1. Распакуйте CargoCalc_Gotov.zip в отдельную папку.
2. Откройте файл CargoCalc.csproj через Visual Studio 2022 (с поддержкой .NET 10) или более новую совместимую версию.
3. Дождитесь восстановления NuGet-пакетов и выберите проект CargoCalc как запускаемый.
4. Нажмите Ctrl+F5 или зелёную кнопку запуска.
5. Если браузер не открылся автоматически, откройте вручную:
   http://localhost:5088

Важно:
- Для первого запуска требуется доступ к NuGet для загрузки Microsoft.EntityFrameworkCore.Sqlite.
- База cargocalc.db создаётся автоматически рядом с запускаемым приложением.
- Отчёт находится в папке Report.
- Перед отправкой преподавателю откройте проект и проверьте запуск в вашей среде. Готовность исходников не заменяет проверку запуска на конкретном компьютере.
